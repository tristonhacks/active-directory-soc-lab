# Active Directory SOC Home Lab

## Overview

This project documents my hands-on Security Operations Center (SOC) home lab.

The goal of this lab is to build an enterprise-style environment and practice:

- Active Directory administration
- Windows security monitoring
- SIEM alert investigation
- Authentication analysis
- Incident response
- Network traffic analysis
- Security event documentation

## Lab Environment

| System | Purpose |
|---|---|
| Windows Server 2022 | Active Directory Domain Controller |
| Windows 10/11 | Domain-joined workstation |
| Wazuh | SIEM / security monitoring |
| Kali Linux | Security testing and event generation |
| pfSense | Firewall / network segmentation |
